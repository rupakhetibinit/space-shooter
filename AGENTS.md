# Project instructions

- Before every push, run `./format-odin.ps1`, then `./format-odin.ps1 -Check` and `./test-game.ps1`.
- Format every non-ignored `.odin` file, including test and tool sources, using the repository's `odinfmt.json`.
- Keep generated binaries, build directories and machine-local editor settings out of commits.
- Preserve user edits and unrelated local files.
